# Elevate Labs AI & ML Internship - Task 2: Exploratory Data Analysis (EDA)

## Overview
This repository contains the completion of Task 2 for the Elevate Labs AI & ML Internship. The objective of this task was to explore and understand the Titanic dataset using statistical summaries and data visualizations before feeding it into machine learning models[cite: 3]. 

## Tools Used
Pandas: Data manipulation and statistical summaries[cite: 3].
Matplotlib & Seaborn: Generating histograms, boxplots, and correlation heatmaps[cite: 3].

## Steps Completed
1. Summary Statistics: Generated statistical summaries for both numeric and categorical columns to understand the data distribution[cite: 3].
2. Visualizing Distributions & Outliers: Plotted histograms for the `Age` distribution and boxplots to detect extreme outliers in passenger `Fare`[cite: 3].
3. Correlation Analysis: Created a heatmap of the correlation matrix to identify linear relationships between numerical features[cite: 3].
4. Pattern Recognition: Built count plots to compare survival rates across different genders and passenger classes, successfully identifying underlying demographic trends[cite: 3].
